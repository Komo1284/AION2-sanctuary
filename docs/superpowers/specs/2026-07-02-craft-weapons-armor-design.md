# 제작효율 계산기 무기·방어구 확장 설계

작성일: 2026-07-02
대상: `craft.php` + `craft/` (기존 악세서리 계산기의 확장)

## 1. 목적·범위

기존 악세서리 3종(목걸이/귀걸이/반지) 계산기에 **무기 9종 + 방어구 7종**을 추가한다.

- **무기 (9)**: 대검(class2=101) 장검(102) 단검(103) 전곤(104) 가더(105) 활(301) 법봉(302) 법서(401) 보주(402)
- **방어구 (7)**: 투구(201) 견갑(202) 상의(203) 하의(204) 장갑(205) 신발(206) 망토(207)
- 팔찌(306)·브로치(307)는 이번 범위에서 **제외**
- 무기의 전설 라인(용암 심장의 공포대검, 침식된 지배자의 포식대검, 루드라의 절멸도, 장비 변경권 등)은 **제외** — 용왕 라인만 계산

## 2. 도메인 차이 (inven 스크레이핑으로 확인)

- 무기·방어구 모두 악세와 동일한 용왕 티어(진→백→명→천→현→응) + 계승/코어직접/달인빛나는직접 구조
- **무기에만 창룡왕 티어 존재** (응룡왕 상위). 창룡왕은 `빛나는 응룡왕 → 창룡왕 계승` 레시피만 있음(직접제작·코어 없음). 창룡왕 계승과 빛나는 창룡왕 승급에는 신규 재료 `폭주한 공포의 사념`, `폭주한 공포의 기운: 무기` 사용 — **시세 구매 가능 아이템**(가격 입력 대상)
- **빛나는 창룡왕 승급은 키나 + 재료 둘 다 소요** (하위 티어 승급은 키나만) — 스키마는 이미 빛나는승급 레시피에 inputs를 허용하므로 문제 없음
- 코어·계승석이 부위군별 별도 아이템: `○○왕의 코어: 무기/방어구/장신구`, `제작 계승석: 무기/방어구/장신구`, `계승석: 무기/방어구/장신구 (영웅)`
- 재료 계열: 무기 = `제련된 ○○ 용족의 뿔` + `찬란한 오리하르콘 광석`, 방어구 = 오리하르콘 계열(정확한 재료명은 구현 시 페이지별 스크레이핑으로 확정), 중간아이템 = `달인의 빛나는 오리하르콘 대검` 등 품목별
- 키나 승급 값은 품목군별로 다름(예: 대검 진1M/천30M/현50M/응100M, 투구 응60M) — 스크레이핑 값 사용

## 3. 목표 티어

- **무기: 창룡왕(기본)**, 방어구·악세: 응룡왕(기본)
- 루트 3개 구조 유지(모든 품목 공통):
  1. 응룡왕 직접제작(달인의 빛나는) — 무기는 이어서 창룡왕 계승
  2. 현룡왕 코어직접 → 계승 체인
  3. 보유 아이템부터 계승 (카드 내 드롭다운, 빛나는 포함)
- 무기의 보유 선택지는 진룡왕~**응룡왕**(+빛나는) — 목표가 창룡왕이므로. 방어구·악세는 진~현룡왕(+빛나는)

## 4. 교환(대체가) 규칙 — 부위군별 일반화

- `제작 계승석: 무기` = **달인의 빛나는 무기 9종 중 최저가** (1:1 교환, 직접구매 불가 → 자기 시세 무시)
- `제작 계승석: 방어구` = 달인의 빛나는 방어구 7종 중 최저가 (동일)
- `제작 계승석: 장신구` = 기존대로 달인의 빛나는 악세 3종 최저가
- `계승석: ○○ (영웅)` 3종 모두 무료(is_core=1)
- `찬란한 오리하르콘 광석` ↔ `찬란한 오드` 1:1 → min 적용 (기존 원석 규칙과 동일)
- 계승 레시피의 코어 제거(계승석만 소비) — 무기·방어구에도 동일 적용. 코어직접 레시피의 코어는 무료 유지
- **데이터 주도 구현**: 중간아이템 category를 `중간아이템-무기/방어구/장신구`로 세분화하고, 계승석 대체가는 해당 카테고리 최저가로 계산(하드코딩 목록 제거). 기존 3종 악세의 category 변경은 seed 버전 범프 시 자동 동기화(schema의 category re-sync)

## 5. 코드 구조

- **DB 스키마 불변**. `craft_recipes.accessory` 컬럼에 품목명('대검','투구' 등) 저장. 분류는 코드 상수:
  `무기=[대검,장검,단검,전곤,가더,활,법봉,법서,보주]`, `방어구=[투구,견갑,상의,하의,장갑,신발,망토]`, `장신구=[목걸이,귀걸이,반지]`
- **seed 파일 분리**: `craft/seed/accessories.php`(기존 데이터 이동), `craft/seed/weapons.php`, `craft/seed/armor.php` → `seed_data.php`가 병합. `CRAFT_SEED_VERSION` 범프로 배포(가격 데이터 무손실 — additive 시딩)
- **calc.php 일반화**:
  - 티어 순서에 `창룡왕` 추가
  - `craft_localize_entry` 하드코딩 제거 → `"{티어}의 {품목}"` 문자열 생성으로 대체
  - 목표 티어 결정 함수: 무기 → 창룡왕, 그 외 → 응룡왕
  - 교환 규칙을 카테고리 주도로 재작성(§4)
- **view.php**: 상단 2단 선택(분류 → 품목), 보유 옵션 품목군별 상한(§3), 루트 라벨은 목표 티어에 맞게 동적 생성

## 6. 검증

- 기존 악세 테스트 전부 회귀 통과 + 무기(창룡왕 목표)·방어구 검증 추가(test_calc.php, 가격 스냅샷 원복 유지)
- seed 데이터는 리뷰 단계에서 inven 재스크레이핑 대조(악세 확장 때와 동일 방식)
- 배포는 매 태스크 커밋→push→서버 pull→서버 검증. **craft_materials DROP/DELETE 금지** (CLAUDE.md 규칙)
